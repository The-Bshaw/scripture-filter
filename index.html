Herald / Apollos prototype

Sermons by Scripture

This demo uses current sermon data from the public Apollos demo site, but models each record with the Herald fields book, start_chapter, and end_chapter. Multiple passages are stored as PHP-style serialized arrays. When you choose a book, the page finds the matching array index and sorts only by that book’s chapter and verse.

Filter By
Sorting logic: selected book → matching passage index → start chapter → start verse → end chapter → end verse → sermon date as a final tie-breaker. Click “Show raw Herald-style fields” on any sermon to see the scalar/serialized values the sorter is actually reading.
